# ✈️ Flight Delay Prediction

A full-stack machine learning application that predicts whether a flight is likely to be delayed based on flight details, schedule, route, and weather conditions.

The project demonstrates an end-to-end ML workflow including data generation, preprocessing, feature engineering, model training, model comparison, REST API development, and frontend deployment.

## 📌 Features

- Predicts whether a flight will be delayed
- Displays estimated delay probability
- Uses flight, route, schedule, and weather information
- Interactive React frontend
- Flask REST API
- Input validation
- Feature engineering for time-based variables
- Comparison of multiple machine learning models
- Feature-importance analysis
- Deployed frontend and backend
